# رقيب — النسخة المصححة الجاهزة لرفع GitHub Pages

## ما الذي أصلحناه؟
- حذفنا الدائرة والبطاقة المائلة وعلامة الاستفهام ووسم «من قلب الميدان» من المقدمة، ونسقنا زر «ابدأ التحدّي» على الهاتف.
- أصلحنا مشكلة البطاقات: **فتح الأسئلة لم يعد يتوقف على تفعيل Firebase**؛ تقدر تجرب اللعبة الآن.
- يختار الزائر بطاقة واحدة، ويجيب مرة واحدة من نفس المتصفح. البطاقات نفسها تظل متاحة لأي زائر آخر.
- أضفنا معاينة آمنة للوحة الفريق بمشاركات وهمية واضحة أنها للشرح، بينما البيانات الحقيقية لا تظهر إلا لصاحب صلاحية.

## مهم جدًا بخصوص حفظ الإجابات
إذا كان `firebase-config.js` لا يزال يحتوي `PUT_...` فاللعبة تعمل **كتجربة محلية فقط**؛ تعرض السؤال وشاشة الشكر لكن **لا ترسل أي إجابة لكم**. هذه ليست مشاركة حقيقية. هذا مقصود لتتمكنوا من استعراض التصميم قبل تفعيل الربط.

قبل وضع QR على الستاند، **لازم** إعداد Firebase واختبار إرسال إجابة حقيقية وظهورها في لوحة الفريق.

## كيف تحدثون ملفات GitHub
1. افتحوا المستودع `raqeeb-game` > `Add file` > `Upload files`.
2. ارفعوا **كل الملفات الجديدة من هذا المجلد نفسه** (لا ترفعوا ZIP ولا مجلد خارجي)، ووافقوا على استبدال الملفات بنفس أسمائها.
3. اضغطوا `Commit changes`. إذا واجهت واجهة GitHub رفضًا للأسماء المتكررة، افتحوا الملف في المستودع واضغطوا رمز القلم ثم الصقوا المحتوى الجديد أو استخدموا VS Code / GitHub Desktop لاستبدال الملفات.
4. بعد نشر GitHub Pages مجددًا، حدّث الصفحة تحديثًا كاملًا (Ctrl + Shift + R). الرابط وQR لا يتغيران.
5. افتحوا `https://s6244s05h-beep.github.io/raqeeb-game/` لتجربة اللعبة، و `https://s6244s05h-beep.github.io/raqeeb-game/admin.html?preview=1` **لمعاينة** لوحة النتائج بدون تسجيل دخول (أمثلة وهمية فقط).

## تفعيل النتائج الحقيقية
1. افتحوا https://console.firebase.google.com وسجلوا مشروعًا مجانيًا.
2. أضيفوا Web App وخذوا `apiKey`, `authDomain`, `projectId`, `appId` والصقوها في `firebase-config.js` بدلاً من قيم `PUT_...`.
3. Authentication > Sign-in method: فعلوا Anonymous (للزوار) و Email/Password (للفريق).
4. Authentication > Users: أنشئوا مستخدمًا للفريق، وخذوا UID الخاص به فقط. **لا تضعوا كلمة المرور في GitHub**.
5. Firestore Database: أنشئوا قاعدة بيانات، وضعوا محتوى `firestore.rules` مع تبديل `PASTE_TEAM_ADMIN_UID_HERE` إلى UID الفريق، ثم Publish.
6. Authentication > Settings > Authorized domains: أضيفوا `s6244s05h-beep.github.io` إذا دعت الحاجة.
7. ارفعوا `firebase-config.js` المعدل إلى GitHub.
8. جربوا من متصفح الزائر اختيار بطاقة والإجابة، ثم افتحوا `/admin.html` وسجلوا دخول الفريق. إذا ظهرت الإجابة، الربط اكتمل.

* ملاحظة: الربط عبر Firebase لا يمنع شخصًا من اللعب بجهاز آخر أو بعد مسح بيانات المتصفح؛ هو قيد لكل حساب زائر مجهول ومتصفحه.
* بيانات Firestore لا يستطيع الزوار العاديون قراءتها بحسب قواعد الملف؛ صفحة الإدارة ليست معتمدة على إخفاء رابطها لحمايتها.
* الصفحة `admin.html?preview=1` معاينة فقط، ولا تكشف بيانات فعلية أو تسجّل دخول الفريق.
* `stand.html` موجود أيضًا لطباعة A4 بعد إنشاء QR من رابط GitHub Pages النهائي.
